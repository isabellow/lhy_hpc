LMN88 260720, onset-aligned

Each row is one cell and each column a time bin (20 ms) relative to event onset (dashed line). Top row: checks (site opened, contents unchanged, <= 1.5 s). Bottom row: retrievals (seed removed). Left: a seed the bird should expect (its own caches, or baits it has already found in any earlier interaction with the site). Right: empty checks / retrievals of baits at a site the bird had never opened. Checks of undiscovered baits are left out.

Activity: each cell's instantaneous firing rate over the whole session was divided by its session SD (+0.01) and a running-average baseline (window 30) was subtracted (pop_normalize), so units are SDs from baseline; this trace was then averaged across events and Gaussian-smoothed (sigma 20 ms). Colour limits -1 to 1 SD (red above, blue below baseline).
Per cell, events were excluded where the unit's amplitude in a 1-min window around the event was below 0.7x its session average.
A cell/condition is drawn only with >= 3 usable events. Cells: all good units, session firing rate > 0.1 Hz.

Sorting: ordered by the time of each cell's peak (the whole window) in empty checks, earliest on top.
Cross-validated: empty checks events were split in half (alternating events in time); half 0 set the order and the empty checks panel shows only half 1. The other panels use all their events.

All panels show the same cells in the same rows; grey rows had too few events in that condition.

Per panel:
  occupied checks: 41 cells, 83 events, 1 session, 1 bird; median event duration 0.30 s
  empty checks: 41 cells, 575 events, 1 session, 1 bird; median event duration 0.24 s
  cached retrievals: 40 cells (of 41 rows), 34 events, 1 session, 1 bird; median event duration 1.44 s
  baited retrievals: 0 cells (of 41 rows), 0 events, 0 sessions, 0 birds; median event duration n/a
